# Repository Guidelines

Read `../CFD-Agent-Roadmap.md` before any task involving CFD-Memo architecture, OpenFOAM automation, experiment design, memory schemas, or research deliverables.

Keep this directory as the code and experiment scaffold. Do not copy source application forms, schedules, spreadsheets, or unpublished research documents from `../科研立项/` into this project.

Stage B is limited to project structure, schemas, baseline case templates, sample logs, and documentation. Implement planner, generator, validator, runner, diagnoser, memory, and reporter behavior in later stages after interfaces are stable.
